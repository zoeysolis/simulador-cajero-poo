## Características:

Gestión de Estados: Maneja el saldo actual de forma dinámica durante la sesión.

Encapsulamiento (POO): La lógica de depósitos y retiros está protegida dentro de una clase, evitando saldos negativos.

Interfaz wxPython: Uso de cuadros de diálogo (MessageDialog) para confirmar operaciones y errores.

Validación: Controla que el usuario no intente retirar más dinero del disponible o ingrese valores no numéricos.
